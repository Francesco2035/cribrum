# Documentazione in italiano

- `code/`: una pagina per file di codice, con la stessa struttura del repo (`core/windows.py` → `code/core/windows.md`). Librerie usate, logica, scelte e costrutti non banali. I `NOTES.md` sono le note di progettazione iniziali di ogni cartella.
- `code/config/`: il significato di ogni parametro dei file in `config/` e come è stato scelto.
- `miglioramenti.md`: idee di miglioramento fase per fase, con il modo di misurarle (versione inglese ridotta: `../future_work.md`).
- `taratura_finestre.md`: come leggere il report di `scripts/tune_windows.py`.
- `libs/`: appunti sulle librerie, comprese quelle previste ma non ancora usate.
- `plans/`: il piano originale del grafo (`graph_workflow.md`) e della GUI (`gui.md`).

Comandi e panoramica sono in inglese: `../usage.md` e `../pipeline.md`.
